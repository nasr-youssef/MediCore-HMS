# 🏥 MediCore HMS

## 📌 Overview

MediCore is a Full-Stack Hospital Management System designed to streamline healthcare operations including patient management, appointment scheduling, billing, medical records, and hospital bed management.

The system provides separate dashboards for Admins, Doctors, and Patients with secure authentication and role-based access control.

---

## 🚀 Features

- 🔐 Authentication & Authorization
- 👨‍⚕️ Doctor Dashboard
- 🧑‍🤝‍🧑 Patient Management
- 📅 Appointment Scheduling
- 💳 Billing & Invoices
- 🛏️ Bed Management
- 📋 Medical Records
- 📊 Role-Based Dashboards

## ▶️ How to Run

1. Install XAMPP
2. Import the database file into phpMyAdmin
3. Move the project folder to:
   C:/xampp/htdocs/
4. Start Apache & MySQL
5. Open:
   http://localhost/MediCore/medicore-login.html
